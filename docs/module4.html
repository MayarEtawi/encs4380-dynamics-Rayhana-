QUICK REFERENCE

How to read a response curve

Use the methods from Modules 1 and 3 to estimate the hidden values.

01

First-order · step

For a unit-step input, the final output gives K. The time to reach 63.2% of that output gives τ.

y(t) = K(1 − e−t/τ)
02

First-order · sine

Use the measured phase lag and known input frequency to estimate τ; then use the output amplitude to estimate K.

M = 1 / √(1 + (ωτ)²)
03

Second-order · step

Read the percentage overshoot to estimate ζ, then use the first peak time to estimate ωn.

Mp = e−πζ/√(1−ζ²)
