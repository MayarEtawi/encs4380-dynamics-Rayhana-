1. Motor and Hardware Specifications

The RAYHANA Micromouse uses two N20 DC geared motors with magnetic encoders. Each motor is intended to be controlled through a DRV8833 dual H-bridge driver using an ESP32 microcontroller.

2. First-Order Motor Model

Transfer function: G(s) = K / (τs + 1)

Input: PWM duty cycle (%).
Output: Motor shaft speed (RPM).

Plant gain: K = ΔRPM / ΔPWM

Time constant: τ is the time to reach 63.2% of the total speed change after the PWM step.

3. Control Objective and Specifications

Control objective: Maintain stable and accurate wheel speed to support predictable Micromouse motion.

Damping ratio target 0.6 ≤ ζ ≤ 0.8
Proposed overshoot ≤ 10%
Proposed settling time ≤ 1.0 s (2% band)
Proposed steady-state error ≤ 2%
PWM output limits 0–100%

Justification: The Micromouse must maintain consistent speed during short maze movements. Excessive overshoot or slow settling may reduce movement accuracy and navigation reliability.

Limitations

The first-order model neglects nonlinear friction, gearbox backlash, motor dead zones, changing battery voltage, encoder noise and wheel loading.

Simulation results are not equivalent to experimental verification.

5. Project Integration

The intended hardware configuration uses an ESP32 microcontroller, two N20 encoder motors, and a DRV8833 motor driver.

The PWM controller will eventually use encoder speed feedback to regulate the left and right wheel speeds.

The current page demonstrates the control design process through simulation.
