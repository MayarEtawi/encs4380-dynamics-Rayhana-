Module 1 — First-Order Time Response

Explore how gain K and time constant τ affect the response of a first-order sensor.

System Equation

τ dy/dt + y = Kx

This equation describes a first-order system. The output does not change instantly; it approaches its final value gradually.

What do K and τ mean?

K Gain: controls the final output level.

τ Time Constant: controls how fast the response changes.
