P2 — Slow Sensor

Feedback loop with a Slow Sensor

Negative feedback with a slow sensor: e(t) = r(t) − ys(t), instead of r(t) − y(t). The sensor follows τs · dys/dt = y − ys. Increasing the sensor time constant introduces more delay into the feedback loop.

True output vs. sensor measurement

The graph compares the true plant output y(t) with the delayed sensor measurement ys(t). The dashed line represents the desired setpoint. Increasing τs makes the sensor response slower and may cause overshoot or oscillations.

Control signal and saturation

The control signal u(t) is generated by the PID controller using the measured sensor output. Dashed lines indicate the actuator limits ±Umax. Conditional integration anti-windup prevents further integral accumulation when saturation would be increased.

What should I notice?

Fast sensor: When τs is small, the sensor measurement follows the actual plant output closely. The PID controller receives feedback quickly.

Slow sensor: When τs increases, the sensor measurement lags behind the true output. The controller reacts to delayed information.

Overshoot: Because of delayed feedback, the controller may continue applying a strong command even after the true output has approached the setpoint.

Oscillation: With suitable PID gains and enough sensor delay, the system may oscillate or become unstable.

A slow sensor does not guarantee oscillation for every configuration. Stability depends on the plant, sensor dynamics and controller gains.
