System Model

Frequency-response equations

G(s) = 1 / (τs + 1)
M = 1 / √(1 + (ωτ)²)
φ = −atan(ωτ)

M is the amplitude ratio. Negative phase means the output lags the input.

Input and output

x(t) = sin(ωt)
y(t) = M sin(ωt + φ)
ω = 2πf

Unit gain K = 1, steady state. f in Hz, ω in rad/s, τ in seconds.
