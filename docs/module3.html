System model

mẍ + bẋ + kx = F(t)

A mass connected to a spring and a damper starts at rest. At t = 0, a constant force F₀ is applied.

From physical parameters to response

ωn = √(k/m)   ·   ζ = b / (2√(mk))

m: mass · b: viscous damping · k: spring stiffness.
The equilibrium displacement is x∞ = F₀/k. Capital K = 1/k is the static gain.

Equations & measurement definitions

Model, gain, and assumptions

G(s) = X(s)/F(s) = 1/(ms² + bs + k) = Kωn²/(s² + 2ζωns + ωn²), where K = 1/k. A positive force step is applied to a linear mass–spring–damper at rest. The equilibrium reference is F₀/k. If b = 0, this is an equilibrium position, but the response never converges to it.

Closed-form displacement in each damping case

Let f = F₀/k and ωd = ωn√(1 − ζ²).

Underdamped (0 ≤ ζ < 1):
x(t) = f[1 − e−ζωₙt(cos(ωdt) + ζ sin(ωdt)/√(1 − ζ²))]

Critically damped (ζ = 1):
x(t) = f[1 − (1 + ωnt)e−ωₙt]

Overdamped (ζ > 1):
x(t) = f[1 + (p₂ep₁t − p₁ep₂t)/(p₁ − p₂)]
p₁, p₂ = −ζωn ± ωn√(ζ² − 1)

Rise time, peak, overshoot, and settling

Rise time is the first 90% crossing minus the first 10% crossing of the equilibrium displacement. For ζ < 1, the first peak occurs at π/ωd; its overshoot is 100(xpeak/f − 1)%. The equivalent formula is 100e−πζ/√(1−ζ²).

Settling time is the final entry into [0.98f, 1.02f], after which the exact response remains in the band. It is found from exact crossings, rather than the approximate 4/(ζωn) rule. Values outside the selected time window are reported as outside the window. Zero damping has no settling time.

Euler and Runge–Kutta methods

With state q = [x, v] and derivative g(q) = [v, (F₀ − bv − kx)/m], Euler uses qn+1 = qn + hg(qn). Both state components use the old state.

RK4 uses a₁ = g(q), a₂ = g(q + ha₁/2), a₃ = g(q + ha₂/2), a₄ = g(q + ha₃), then qn+1 = q + h(a₁ + 2a₂ + 2a₃ + a₄)/6. The last step is shortened when necessary to end at the exact plot duration.
